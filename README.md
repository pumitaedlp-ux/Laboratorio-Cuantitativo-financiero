# Laboratorio-Cuantitativo-financiero
Repositorio que contiene herramientas de análisis financiero con un enfoque 100% cuantitativo, basadas en programación determinística y estocástica.
El material del laboratorio se compone de 6 pilares:

1. **Financial-Mathematics**
2. **Corporate-Finance-and-Valuation**
3. **Portfolio-Optimization-and-Asset-Allocation**
4. **Fixed-Income-and-Bond-Analytics**
5. **Quantitative-Risk-Management**
6. **Financial-Econometrics-and-Time-Series***
7. **Stochastic-Processes-and-Financial-Modeling**
8. **Stochastic-Calculus-and-Differential-Equations**
9. **Derivative-Pricing-and-Financial-Engineering**
10. **Option-Pricing-and-Hedging**
11. **Credit-Risk-and-Default-Modeling**
12. **Real-Options-and-Investment-Analysis**
13. **Monte-Carlo-and-Numerical-Finance**
14. **Algorithmic-Trading-and-Market-Microstructure**
15. **Optimal-Control-and-Portfolio-Theory**
16. **Digital-Asset-and-DeFi-Quantitative-Modeling**
17. **Insurance-and-Actuarial-Risk-Modeling**
